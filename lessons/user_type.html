Користувацькі типи даних у Pascal

Інтерактивний урок зі створення та використання власних типів даних: псевдонімів, діапазонів, переліків та записів (record).

1. Секція створення типів `type`

Стандартних типів (integer, real, string) не завжди достатньо. У Pascal ви можете створювати **власні типи даних** у спеціальному блоці type, який іде до блоку var.

program CustomTypes;

type                    { Блок оголошення типів }
  TScore = integer;     { Створення власного псевдоніма }
  TName = string[30];

var                     { Блок оголошення змінних }
  studentScore: TScore;
  studentName: TName;

begin
  studentScore := 100;
  studentName := 'Олексій';
  writeln(studentName, ' має бал: ', studentScore);
end.
Ключове словоОпис
typeпочаток розділу оголошення нових типів даних
=використовується для визначення типу (на відміну від : в оголошенні змінних)
T...за домовленістю назви користувацьких типів починають з літери T (від Type)

Запам'ятай: Тип — це лише «шаблон» або «креслення». Самі дані зберігаються у змінних, які створюються на основі цього типу у блоці var.

2. Інтервальний та перелічувальний типи

Pascal дозволяє обмежувати можливі значення змінних або створювати список власних текстових значень.

Інтервальний тип (Subrange)

Задає чіткий діапазон значень «від .. до»:

type
  TMark = 1..12;        { Оцінка від 1 до 12 }
  TDaysInMonth = 1..31;
  TLatinChar = 'A'..'Z';

Перелічувальний тип (Enumerated)

Задає список можливих слів-значень:

type
  TDays = (Mon, Tue, Wed, Thu, Fri, Sat, Sun);
  TSeason = (Winter, Spring, Summer, Autumn);
Пояснення синтаксису. Інтервальний тип використовує дві крапки ... Перелічувальний тип записується в круглих дужках (...).
Швидка практика. Оголоси тип THour для годин доби (від 0 до 23) та тип TTrafficLight для кольорів світлофора (Red, Yellow, Green). 
type
  THour = 0..23;
  TTrafficLight = (Red, Yellow, Green);

3. Записи (`record`)

Запис (record) — це складний тип даних, який об'єднує декілька змінних різних типів (полів) під одним іменем.

type
  TStudent = record
    name: string;
    age: integer;
    avgGrade: real;
  end;

var
  s1: TStudent; { Створення змінної типу TStudent }

Доступ до полів через крапку

begin
  s1.name := 'Анна';
  s1.age := 16;
  s1.avgGrade := 10.5;

  writeln('Студент: ', s1.name, ', Середній бал: ', s1.avgGrade:0:1);
end.
Обери вірне звернення. Як правильно надати вік `18` об'єкту `p` типу `TPerson` з полем `age`?

4. Оператор `with`

Щоб не писати щоразу назву змінної-запису з крапкою, використовують оператор with.

Звичайний підхід

s1.name := 'Іван';
s1.age := 15;
s1.avgGrade := 9.8;

З використанням with

with s1 do
begin
  name := 'Іван';
  age := 15;
  avgGrade := 9.8;
end;

Повна програма із записом та масивом типів

program BookStore;

type
  TBook = record
    title: string;
    author: string;
    price: real;
  end;

var
  myBook: TBook;

begin
  with myBook do
  begin
    write('Введіть назву книги: ');
    readln(title);
    write('Введіть автора: ');
    readln(author);
    write('Введіть ціну: ');
    readln(price);
  end;

  writeln('--- Книга додана ---');
  writeln('"', myBook.title, '", автор: ', myBook.author, ' (', myBook.price:0:2, ' грн)');
end.

5. Практика — пишемо самі

Завдання 1. Точка на площині. Створити тип TPoint із координатами $X$ та $Y$ (цілі числа). Ввести значення координат та вивести їх.
Код для вчителя
program PointDemo;

type
  TPoint = record
    x, y: integer;
  end;

var
  p: TPoint;

begin
  write('Введіть X: '); readln(p.x);
  write('Введіть Y: '); readln(p.y);

  writeln('Точка з координатами: (', p.x, '; ', p.y, ')');
end.
Завдання 2. Інформація про автомобіль. Оголосити тип TCar (марка, рік випуску, ціна). Описати змінну, заповнити через with та вивести дані.
Код для вчителя
program CarDemo;

type
  TCar = record
    brand: string;
    year: integer;
    price: real;
  end;

var
  car1: TCar;

begin
  with car1 do
  begin
    brand := 'Toyota';
    year := 2020;
    price := 15500.50;
  end;

  writeln('Авто: ', car1.brand, ', Рік: ', car1.year, ', Ціна: $', car1.price:0:2);
end.
Завдання 3. Прямокутник із точок. Описати тип TRectangle, який містить дві поля типу TPoint (верхній лівий та нижній правий кути).
Код для вчителя
program RectDemo;

type
  TPoint = record
    x, y: integer;
  end;

  TRectangle = record
    topLeft: TPoint;
    bottomRight: TPoint;
  end;

var
  r: TRectangle;

begin
  r.topLeft.x := 0;
  r.topLeft.y := 10;
  r.bottomRight.x := 20;
  r.bottomRight.y := 0;

  writeln('Верхній лівий кут X: ', r.topLeft.x);
end.
