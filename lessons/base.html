1. Будова програми

program FirstProgram;   { назва програми }

var                     { блок змінних }
  age: integer;

begin                   { початок команд }
  age := 14;
  writeln('Age: ', age);
end.                    { кінець програми }
ЕлементЩо означає
programназва програми; у сучасних середовищах рядок часто можна опустити
varблок оголошення змінних
beginпочаток блоку команд
end.кінець головної програми; тут саме крапка
;розділяє оператори/оголошення

Запам'ятай: Pascal любить чітку структуру. Спочатку оголошуємо потрібні дані, потім у begin ... end. пишемо дії.

2. Змінні

Змінна — це іменоване місце для збереження значення. Синтаксис оголошення:

var
  ім'я_змінної: тип;

Кілька змінних одного типу можна оголосити разом:

var
  a, b, sum: integer;
  name: string;

Присвоєння значення

a := 10;
name := 'Max';
Пояснення синтаксису. : читаємо як «має тип», а := — «отримати/присвоїти значення». Тобто age: integer — age має тип integer; age := 14 — age отримує 14.
Швидка практика. Оголоси змінні studentName, age і height для імені, віку та зросту. 
var
  studentName: string;
  age: integer;
  height: real;

4. Виведення та введення

Виведення

write('Hello');
writeln('Hello');

writeln після виведення переходить на новий рядок, write — ні.

Введення

readln(age);

Програма чекає, поки користувач введе значення, і записує його у змінну.

Повна програма

program UserInfo;

var
  name: string;
  age: integer;

begin
  write('Enter your name: ');
  readln(name);

  write('Enter your age: ');
  readln(age);

  writeln('Hello, ', name, '!');
  writeln('You are ', age, ' years old.');
end.
Для вчителя. Пройдіть код зверху вниз. Попросіть учня перед запуском спрогнозувати, на якому рядку програма зупиниться та чекатиме користувача.

program Calculator;

var
  a, b: integer;

begin
  write('a = ');
  readln(a);
  write('b = ');
  readln(b);

  writeln('Sum = ', a + b);
  writeln('Difference = ', a - b);
  writeln('Product = ', a * b);
  writeln('Integer division = ', a div b);
  writeln('Remainder = ', a mod b);
end.

У Pascal div і mod особливо важливі для задач із цілими числами. Не використовуйте div, якщо дільник дорівнює нулю.

6. Форматування дробових чисел

var
  price: real;

begin
  price := 12.34567;
  writeln(price:0:2);
end.

:0:2 означає: вивести число з 2 цифрами після десяткової крапки. Результат: 12.35.

7. Практика — пишемо самі

Завдання 1. Візитівка. Користувач вводить ім'я та вік. Програма вітається і показує дані.
Код для вчителя
program Card;

var
  name: string;
  age: integer;

begin
  write('Name: ');
  readln(name);
  write('Age: ');
  readln(age);

  writeln('Hello, ', name, '!');
  writeln('Age: ', age);
end.
Завдання 2. Сума двох чисел. Ввести два цілі числа та знайти їх суму.
Код для вчителя + пояснення
program SumTwo;

var
  a, b, result: integer;

begin
  readln(a);
  readln(b);
  result := a + b;
  writeln('Result = ', result);
end.

result := a + b; — спочатку Pascal обчислює праву частину, потім записує результат у result.

Завдання 3. Прямокутник. Ввести довжину і ширину. Обчислити площу та периметр.
Код для вчителя
program Rectangle;

var
  a, b, area, perimeter: real;

begin
  write('Length: ');
  readln(a);
  write('Width: ');
  readln(b);

  area := a * b;
  perimeter := 2 * (a + b);

  writeln('Area = ', area:0:2);
  writeln('Perimeter = ', perimeter:0:2);
end.
Завдання 4. Вік наступного року. Учень вводить свій вік. Програма показує, скільки буде наступного року.
Рішення
program NextAge;

var
  age: integer;

begin
  write('Your age: ');
  readln(age);
  writeln('Next year you will be ', age + 1);
end.
Завдання 5. Секунди. Ввести кількість хвилин та перевести її в секунди.
Рішення
program MinutesToSeconds;

var
  minutes, seconds: integer;

begin
  write('Minutes: ');
  readln(minutes);
  seconds := minutes * 60;
  writeln('Seconds = ', seconds);
end.

9. Підсумкова програма

Напишіть мініпрограму «Покупка»: користувач вводить назву товару, ціну та кількість. Програма обчислює загальну вартість.

Рішення для вчителя
program Purchase;

var
  productName: string;
  price, total: real;
  quantity: integer;

begin
  write('Product: ');
  readln(productName);

  write('Price: ');
  readln(price);

  write('Quantity: ');
  readln(quantity);

  total := price * quantity;

  writeln('Product: ', productName);
  writeln('Total: ', total:0:2);
end.

Що перевіряємо: string, integer, real, var, readln, writeln, присвоєння та множення.
