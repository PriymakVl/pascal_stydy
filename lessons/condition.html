1. Що таке умовний оператор?

Умовний оператор (ветвлення) дозволяє програмі приймати рішення: виконувати один блок команд чи інший залежно від того, чи виконується умова (істинна вона чи хибна).

Синтаксис повної форми

if умова then
  оператор_1
else
  оператор_2;

Синтаксис неповної форми

if умова then
  оператор;
Головне правило Pascal: Перед словом else крапка з комою ; НІКОЛИ не ставиться! Крапка з комою завершує весь оператор if-then-else у кінці.

Приклад повної форми

program CheckAge;

var
  age: integer;

begin
  write('Введіть ваш вік: ');
  readln(age);

  if age >= 18 then
    writeln('Доступ дозволено')
  else
    writeln('Доступ обмежено');
end.

2. Оператори порівняння

Для формування умов використовуються знаки порівняння, які повертають значення типу boolean (true або false):

ОпераціяЗнак у PascalПрикладРезультат
Рівно=5 = 5true
Не дорівнює<>5 <> 3true
Більше>10 > 20false
Менше<4 < 8true
Більше або дорівнює>=7 >= 7true
Менше або дорівнює<=3 <= 2false
Запам'ятай: Для порівняння на рівність у Pascal використовується просто =, а для присвоєння значення змінній — :=. Не плутай їх!

3. Логічні оператори: AND, OR, NOT

Якщо необхідно перевірити кілька умов одночасно, використовують логічні оператори:

ОператорЗначенняОписПриклад
andІ (кон'юнкція)Істинно, коли обидві умови істинні(x > 0) and (x < 10)
orАБО (диз'юнкція)Істинно, коли хоча б одна умова істинна(age < 6) or (age > 65)
notНЕ (заперечення)Змінює значення на протилежнеnot (x = 0)
Важливо про дужки! У Pascal логічні оператори мають вищий пріоритет за оператори порівняння. Тому кожну окрему умову обов'язково треба брати в дужки: (a > 0) and (b > 0).
Швидка практика. Перевірте, чи знаходиться число $x$ у діапазоні від 10 до 50 включно. 
if (x >= 10) and (x <= 50) then
  writeln('Число в діапазоні');

4. Складений оператор (begin ... end)

Якщо у гілці then або else потрібно виконати кілька команд, їх необхідно об'єднати у блок за допомогою begin та end.

program TemperatureCheck;

var
  temp: integer;

begin
  write('Введіть температуру: ');
  readln(temp);

  if temp < 0 then
  begin
    writeln('На вулиці мороз!');
    writeln('Одягайте теплу куртку.');
  end
  else
  begin
    writeln('Тепло або плюс.');
    writeln('Можна йти на прогулянку.');
  end;
end.
Зверніть увагу: після першого end перед else крапка с комою не ставиться!

5. Практика — пишемо самі

Завдання 1. Парне чи непарне. Користувач вводить ціле число. Програма визначає, чи є воно парним.
Код та розбір
program EvenOdd;

var
  num: integer;

begin
  write('Введіть число: ');
  readln(num);

  if num mod 2 = 0 then
    writeln('Число парне')
  else
    writeln('Число непарне');
end.

Пояснення: Оператор mod знаходить остачу від ділення. Якщо остача від ділення на 2 дорівнює 0 — число парне.

Завдання 2. Пошук максимуму з двох чисел. Ввести два числа та вивести більше з них.
Код для вчителя
program MaxTwo;

var
  a, b: integer;

begin
  write('Введіть два числа: ');
  readln(a, b);

  if a > b then
    writeln('Максимум: ', a)
  else
    writeln('Максимум: ', b);
end.
Завдання 3. Оцінка за балами. Ввести бал учня (1-12). Якщо бал $\ge 10$, вивести «Відмінно», якщо $\ge 7$ — «Добре», інакше — «Потрібно попрацювати».
Код з вкладеним if
program GradeCheck;

var
  score: integer;

begin
  write('Введіть ваш бал (1-12): ');
  readln(score);

  if score >= 10 then
    writeln('Відмінно')
  else if score >= 7 then
    writeln('Добре')
  else
    writeln('Потрібно попрацювати');
end.
Завдання 4. Знижка на покупку. Ввести суму покупки. Якщо сума перевищує 1000 грн, надати знижку 10% та вивести кінцеву суму.
Рішення
program Discount;

var
  sum, total: real;

begin
  write('Введіть суму покупки: ');
  readln(sum);

  if sum > 1000 then
  begin
    total := sum * 0.9;
    writeln('Вам надано знижку 10%!');
  end
  else
    total := sum;

  writeln('До сплати: ', total:0:2, ' грн');
end.
Завдання 5. Існування трикутника. Дано три сторони $a, b, c$. Перевірити, чи існує трикутник з такими сторонами (кожна сторона має бути меншою за суму двох інших).
Рішення
program TriangleExists;

var
  a, b, c: real;

begin
  write('Введіть 3 сторони: ');
  readln(a, b, c);

  if (a + b > c) and (a + c > b) and (b + c > a) then
    writeln('Трикутник існує')
  else
    writeln('Трикутник НЕ існує');
end.
