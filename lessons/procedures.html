1. Що таке процедура?

Процедура — це окрема допоміжна частина програми (підпрограма), яка має власне ім'я та виконує певну послідовність дій. Вона допомагає розбити велику задачу на менші та уникнути дублювання коду.

Переваги використання процедур:
  • Повторне використання коду (написав один раз — викликаєш багато разів).
  • Покращення читабельності програми.
  • Легший пошук та виправлення помилок.

2. Синтаксис оголошення процедури

Оголошення процедури розміщується у блоці оголошень — **перед** основним `begin` головної програми.

program ProcedureExample;

{ Оголошення процедури }
procedure Greet;
begin
  writeln('--------------------');
  writeln('Ласкаво просимо!');
  writeln('--------------------');
end;

{ Головна програма }
begin
  Greet; { Виклик процедури }
  writeln('Основний блок програми');
  Greet; { Повторний виклик }
end.
ЕлементОпис
procedureКлючове слово для початку оголошення процедури
GreetІм'я процедури (вибирається за тими ж правилами, що й назви змінних)
end;Завершення процедури (зверніть увагу: після end ставиться крапка з комою ;)

3. Передача параметрів (параметри-значення)

Процедури можуть отримувати вхідні дані для обробки. Змінні, що вказуються при оголошенні процедури, називаються формальними параметрами, а значення, що передаються під час виклику — фактичними параметрами.

program PrintMessage;

procedure SayHello(name: string; age: integer);
begin
  writeln('Привіт, ', name, '! Тобі ', age, ' років.');
end;

begin
  SayHello('Олексій', 15); { Передаємо конкретні значення }
  SayHello('Марія', 16);
end.
Пояснення для учнів: При виклику `SayHello('Олексій', 15)` значення `'Олексій'` копіюється у змінну `name`, а `15` — у змінну `age`. Якщо змінити `name` всередині процедури, це **не вплине** на оригінальні дані поза нею.
Швидка практика. Напиши оголошення процедури `PrintSquare`, яка приймає одне ціле число `x` і виводить його квадрат. 
procedure PrintSquare(x: integer);
begin
  writeln('Квадрат числа ', x, ' = ', x * x);
end;

4. Параметри-змінні (з ключевим словом var)

Якщо потрібно, щоб процедура змінила значення змінної, яку їй передали з головної програми, перед параметром ставлять слово var. Це передача за посиланням.

Передача за значенням

procedure IncByOne(a: integer);
begin
  a := a + 1; { змінюється лише копія }
end;

Передача за посиланням (var)

procedure IncByOne(var a: integer);
begin
  a := a + 1; { змінює оригінальну змінну! }
end;

Приклад роботи з `var`:

program SwapNumbers;

var
  x, y: integer;

procedure Swap(var a, b: integer);
var
  temp: integer; { локальна змінна }
begin
  temp := a;
  a := b;
  b := temp;
end;

begin
  x := 5; y := 10;
  writeln('До: x = ', x, ', y = ', y);
  Swap(x, y);
  writeln('Після: x = ', x, ', y = ', y);
end.
Перевірка розуміння. Яке значення виведе `writeln`, якщо використовувати `var`?

5. Локальні та глобальні змінні

Тип змінноїДе оголошенаДе доступна
ГлобальніУ блоці var головної програмиУ всій програмі (включаючи процедури)
ЛокальніВсередині процедури (у її власному блоці var)Тільки всередині цієї процедури
program ScopeExample;

var
  g: integer; { Глобальна змінна }

procedure TestScope;
var
  loc: integer; { Локальна змінна }
begin
  loc := 100;
  g := 50; { Можна змінювати глобальну змінну }
  writeln('Локальна loc = ', loc);
end;

begin
  TestScope;
  { loc := 10; } <--- ПОМИЛКА! Змінна loc тут не існує!
end.

Порада: Намагайтеся використовувати локальні змінні всередині процедур та уникати прямої зміни глобальних змінних без потреби.

6. Практика — пишемо самі

Завдання 1. Рамка для тексту. Написати процедуру `DrawLine`, яка виводить лінію з 20 зірочок (`*`). Викликати її 3 рази.
Код для вчителя
program StarLine;

procedure DrawLine;
var
  i: integer;
begin
  for i := 1 to 20 do
    write('*');
  writeln;
end;

begin
  DrawLine;
  writeln(' Заголовок ');
  DrawLine;
end.
Завдання 2. Периметр і площа прямокутника. Написати процедуру `CalcRect(a, b: real)`, яка обчислює та виводить площу і периметр прямокутника зі сторонами `a` та `b`.
Код для вчителя
program RectangleCalc;

procedure CalcRect(a, b: real);
var
  p, s: real;
begin
  p := 2 * (a + b);
  s := a * b;
  writeln('Периметр: ', p:0:2);
  writeln('Площа: ', s:0:2);
end;

var
  x, y: real;
begin
  write('Введіть довжину та ширину: ');
  readln(x, y);
  CalcRect(x, y);
end.
Завдання 3. Максимум з двох чисел. Написати процедуру `FindMax(a, b: integer; var max: integer)`, яка повертає найбільше з двох чисел у змінну `max`.
Код для вчителя
program MaxTwo;

procedure FindMax(a, b: integer; var max: integer);
begin
  if a > b then
    max := a
  else
    max := b;
end;

var
  n1, n2, result: integer;
begin
  write('Введіть два числа: ');
  readln(n1, n2);
  FindMax(n1, n2, result);
  writeln('Більше число: ', result);
end.
