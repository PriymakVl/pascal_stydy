1. Вбудовані функції Pascal

Функція — це ізольований блок коду, який приймає значення (параметри), виконує обчислення та **обов'язково повертає результат**.

2. Створення власних функцій (function)

Свої функції оголошуються у блоці перед begin головної програми. Назва функції використовується всередині її тіла для повернення значення.

function НазваФункції(параметр1: тип1; параметр2: тип2): ТипРезультату;
var
  // локальні змінні (за потреби)
begin
  // дії
  НазваФункції := результат; // повернення значення
end;

Приклад: Функція обчислення площі прямокутника

program FunctionExample;

// Оголошення функції
function GetArea(a, b: real): real;
begin
  GetArea := a * b; // присвоюємо ім'ю функції результат
end;

// Головна програма
var
  x, y, area: real;
begin
  write('Введіть сторони: ');
  readln(x, y);
  
  area := GetArea(x, y); // виклик функції
  writeln('Площа: ', area:0:2);
end.

Запам'ятай: У функцій у заголовку **завжди вказується тип результату** після двокрапки : real, а всередині обов'язково є присвоєння значення імені функції.

3. Процедури (procedure)

Процедура виконує послідовність дій (наприклад, друк шаблону, очищення екрана), але **не повертає прямого значення** як вираз.

Функція

function Cube(x: integer): integer;
begin
  Cube := x * x * x;
end;

// Виклик у виразі:
ans := Cube(3);

Процедура

procedure PrintLine();
begin
  writeln('--------------------');
end;

// Виклик як окрема команда:
PrintLine;
Для вчителя. Поясніть різницю: функцію можна підставити у writeln(Cube(3)) або математичний вираз, а процедуру викликають тільки як окремий оператор.

4. Параметри-значення та параметри-змінні (var)

За замовчуванням параметри передаються за значенням (створюється копія). Якщо ми хочемо, щоб підпрограма **змінила значення переданої змінної**, використовують слово var.

procedure Swap(var a, b: integer); // var дозволяє змінювати оригінали
var
  temp: integer;
begin
  temp := a;
  a := b;
  b := temp;
end;

5. Локальні та глобальні змінні

Змінні, оголошені у головній програмі, є **глобальними**. Змінні, оголошені всередині функції чи процедури — **локальними** (існують тільки під час виконання цієї підпрограми).

program ScopeDemo;

var
  g: integer; // Глобальна змінна

procedure Test;
var
  l: integer; // Локальна змінна
begin
  l := 5;
  g := 10; // Глобальні змінні видно всюди
end;

begin
  Test;
  // writeln(l); -> ПОМИЛКА! Змінна 'l' тут не існує.
end.

6. Практика — пишемо самі

Завдання 1. Максимум з двох чисел. Напишіть функцію Max(a, b: integer): integer, яка повертає більше з двох чисел.
Код для вчителя
function Max(a, b: integer): integer;
begin
  if a > b then
    Max := a
  else
    Max := b;
end;
Завдання 2. Перевірка парності. Створіть функцію IsEven(n: integer): boolean, яка повертає true, якщо число парне, і false, якщо ні.
Код для вчителя
function IsEven(n: integer): boolean;
begin
  IsEven := (n mod 2 = 0);
end;
Завдання 3. Процедура привітання. Напишіть процедуру SayHello(name: string), яка виводить рядок Вітаю, <ім'я>!.
Код для вчителя
procedure SayHello(name: string);
begin
  writeln('Вітаю, ', name, '!');
end;
Завдання 4. Подвоєння значення. Створіть процедуру DoubleValue(var x: integer), яка збільшує значення змінної у 2 рази.
Код для вчителя
procedure DoubleValue(var x: integer);
begin
  x := x * 2;
end;

8. Підсумкова програма

Напишіть програму, яка містить функцію Power(base, exp: integer): integer для обчислення ступеня числа (наприклад, $2^3 = 8$).

Рішення для вчителя
program PowerProgram;

function Power(base, exp: integer): integer;
var
  i, res: integer;
begin
  res := 1;
  for i := 1 to exp do
    res := res * base;
  Power := res;
end;

var
  a, b: integer;
begin
  write('Основа: '); readln(a);
  write('Показник: '); readln(b);
  
  writeln('Результат: ', Power(a, b));
end.

Що перевіряємо: функція з кількома параметрами, локальні змінні i, res, цикл for та повернення значення через назву функції.
